# דף הבית של מועדון מגשימה

דף אחד לחברות המועדון: כניסה לפורטל בסקולר, חיפוש בכל הכספת והפורטל, הדבר הבא, התחילי כאן, עדכונים, תוכנית החודש, כספת, ערכות למידה, עזרה, הצהרת נגישות.

- כתובת: https://shirgamzo1.github.io/magshima/ (אפשר גם `?q=מילה` לחיפוש מוכן)
- `index.html` התוכן, `style.css` העיצוב, `app.js` מה שזז, `accessibility.html` הצהרת הנגישות.
- **עדכון חדש:** להעתיק את ה-`<details class="update" data-date="YYYY-MM-DD">` הראשון לראש `#updates-list` ולהחליף תאריך, כותרת (בתוך ה-`summary`) ופירוט + קישור (בתוך `.answer`). כל עדכון נפתח בלחיצה עם חץ, ו"לחצי לפירוט" ליד הכותרת מגיע לבד מ-`style.css`. התווית "חדש" מופיעה לבד לשבועיים לפי `data-date`. רק 3 עדכונים גלויים, השאר עוברים לבד ל"עדכונים קודמים".
- **תוכנית החודש:** ארבעה חלונות `details.plan` תחת "תוכנית החודש במועדון" (תכנון חודשי, מפגש שאלות ותשובות, הדרכות מקצועיות, העשרה). הטקסט מגיע מהתמונה החודשית של שיר. לעדכן גם את שם החודש ואת `.when` של המפגש.
- **מפגש חדש:** להוסיף אותו ל-`EVENTS` בראש `app.js` (התחלה וסיום עם `+03:00` בשעון קיץ או `+02:00` בשעון חורף), וליצור קובץ יומן ב-`events/` (שורות CRLF, זמנים ב-UTC). הכרטיס "הדבר הבא" מראה את המפגש הקרוב ונעלם כשאין.
- **ערכה חדשה:** כרטיס ב-`#kits` עם קישור לתיקייה שלה בתוך "ערכות למידה" בכספת, ותמונת שער 480x360 ב-`img/kits/` (חיתוך מ-`~/kits/<kit>/preview/cover-p1.png`).
- **חיפוש:** `data/search.json` נבנה על ידי `~/.claude/club-map/build-map.mjs` (הכספת מדרייב + הפורטל מ-`portal-src.mjs`). קורס או שיעור חדש בפורטל: לעדכן את `portal-src.mjs` ולהריץ `node build-map.mjs --push`.
- אחרי שינוי ב-`style.css` או ב-`app.js` להעלות את `?v=` בקישורים אליהם ב-`index.html` (ובהצהרה), כדי שטלפונים לא יציגו גרסה ישנה.
- צבעים: טקסט רגיל בניגודיות 4.5:1 לפחות. ורוד המותג `#ec47a6` רק כרקע לכפתורים עם טקסט מודגש בגודל 19px ומעלה, ולאייקונים. לטקסט ורוד: `#b8287a`.
- אחרי כל שינוי: commit + push (`GIT_TERMINAL_PROMPT=0 timeout 60 git push`). גיטהאב פייג'ס מתעדכן תוך דקה בערך.
