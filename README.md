# דף הבית של מועדון מגשימה

דף אחד לחברות המועדון: כניסה לפורטל בסקולר, כספת התכנים, ערכות למידה, עדכונים, הלוז החודשי ועזרה.

- כתובת: https://shirgamzo1.github.io/magshima/
- הכול בקובץ `index.html`. אין בנייה ואין סקריפטים.
- עדכון חדש: להעתיק `<article class="card update">` לראש הרשימה תחת "עדכונים חשובים". רק לעדכון האחרון יש `<span class="pill">חדש</span>`.
- לוז: שורות `.row` תחת "הלוז של ___". בתחילת כל חודש להחליף את שם החודש ואת השורות.
- ערכה חדשה: שורה ב-`#kits` עם קישור לתיקייה שלה בתוך "ערכות למידה" בכספת.
- `.todo` = מקום שעוד צריך למלא (צהוב). לא משתפים את הדף כשיש כזה.
- אחרי כל שינוי: commit + push. גיטהאב פייג'ס מתעדכן תוך דקה בערך.
